Demo workflow

測試流程

  1. 先用主帳號登入，設定貨物、安全庫存與現有庫存。
  2. 再以分店帳號登入，依貨物清單填寫要貨數量並送出。
  3. 回到主帳號後台，查看各店回報與建議叫貨量。
  4. 如需重新測試，可在主帳號畫面匯出或重置資料。

System scope

這個測試版已完成的功能

  • 多店登入角色切換：主帳號與分店帳號
  • 主帳號維護貨品資料、安全庫存、現有庫存
  • 分店依貨物清單填報需求數量與備註
  • 主帳號彙整各店需求並產生建議叫貨量
  • 支援手機版排版與 PWA 安裝
  • 支援 JSON 匯出與匯入，方便後續接後端

Next phase

  • Excel / CSV 匯入貨品與報表下載
